# Literature notes

One file per paper actually read, named by arXiv id (e.g. `2512.10101.md`). A note is written when
a paper is read, not when it is cited in passing.

Each note states, in this order:

1. **Reference** — full citation, arXiv id and version, date read.
2. **What it claims** — the results, as the authors state them.
3. **What it actually proves** — separated from what it asserts, argues, or assumes.
4. **Conventions** — how its notation maps onto `CONVENTIONS.md`. Every discrepancy listed.
5. **What we use from it** — the specific equations or statements this project relies on, by
   equation number, and whether we verified them independently.
6. **Verbatim quotes** — where the paper is quoted in support of the claim under test, quote it
   exactly, with the location.
